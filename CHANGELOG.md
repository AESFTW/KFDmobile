# KFDmobile 1.0.0

Initial public release. Android version code 32.

- Encrypted EKC container management, keys and groups, USB keyloader communication, and local/remote storage.
- Settings > About contains Credits and Third-party licenses, below Appearance.
- Contributor profiles and project links are available in Credits.

The APK is unchanged from the approved production build. Release-mode packaging, signature continuity, version, ZIP integrity and 16 KB alignment were previously verified. No new phone or radio test was performed for this publication. Existing API warnings remain.

Known limitation: KVL Keyload-All can fail in Emulate. Transfer ARC4, AES and DES individually. Hardware compatibility is not guaranteed for every phone, adapter and radio combination.

Public history starts at this release. Credits and upstream licenses are preserved. ComSec0's accepted source-directory and README contributions are included. Based on the original KFDtool Windows application and OmahaCommSys fork.
